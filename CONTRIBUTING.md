# Contributing to VitaDroid

Contributions, bug reports and technical research are welcome.

## Priorities

- APK format validation and security
- Binary AndroidManifest.xml parsing
- ARMv7 shared library analysis
- Reusable compatibility components
- File selection and controller mapping
- Automated tests
- Documentation

## Development rules

1. Create a separate branch for changes.
2. Explain changes in pull requests.
3. Include tests when practical.
4. Do not submit commercial APKs or copyrighted game assets.
5. Document third-party code and its license.
6. Do not claim game compatibility without testing.

Current support is experimental. APK execution is not implemented.
